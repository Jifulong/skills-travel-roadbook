# skills-travel-roadbook

> 根据攻略生成路线图，包括天气等

把一段自驾行程文本变成路书 —— 逐日驾车路线图、段间里程与耗时、景点实景照片、海拔与天气，
产出本地可交互页面和可分享的单文件 HTML / PDF / 图片。

这是一个 [Claude Code](https://claude.com/claude-code) skill。

## 它解决什么

你已经把路线定好了：

```
1:成都—天全服务区—折多山—格底拉姆天空之城——住新都桥
2:住宿地—雅江天路十八弯—勒通古镇—长青春科尔寺——住理塘
3:理塘—格聂南线（铁匠山垭口，下则通村，格聂之眼，格聂神山）——住巴塘
```

想要的是把它变准确、可视、能发给同行的人。**这是解析器不是规划器** ——
不替你重新规划行程，只把你写的这份变成路书。

## 安装

```bash
git clone <此仓库> ~/.claude/skills/travel-roadbook
```

重启 Claude Code 后，贴上行程文本即可触发。

## 需要准备

| | 必需 | 说明 |
|---|---|---|
| 高德 Web 服务 key | ✅ | 地理编码 + 驾车路径 + POI 照片，[免费不绑卡](https://lbs.amap.com) |
| 出发日期 | 建议 | 没有日期天气就对不上行程 |
| 高德 JS API key + 安全密钥 | 仅交互地图 | 与上面那个是**两个不同的 key** |
| 小红书 Cookie | 仅补图 | 见 SKILL.md |

天气与海拔走 Open-Meteo，**免 key**。

首次使用请填 `tools/index.html` 顶部的 `PUT_YOUR_AMAP_*` 占位符。

## 产出

- `index.html` — 本地交互版：高德底图、日期切换、点开景点看大图与原帖链接
- `<标题>.html` — 独立单文件，双击即开、零外部请求、可离线（微信传不了 html，用下面两个）
- PDF / PNG — 微信可直接预览
- `data.json` — 结构化数据，可自行二次消费

## 文档

- **[SKILL.md](SKILL.md)** —— 完整流程 + **13 条实测踩出来的坑**（这部分才是核心价值：
  高德定位错了不报错、缓存浅拷贝别名 bug、小红书 461 是账号级配额、全局 `svg` 选择器
  污染地图图层、超过 8 天的预报分歧可达 9.7°C……）
- **[NOTICE.md](NOTICE.md)** —— 第三方来源与许可。**含 GPL-2.0 组件**（小红书签名引擎），
  不需要小红书的话删掉即可宽松分发，其余功能不受影响。
